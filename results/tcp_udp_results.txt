PROJECT: Network Performance Analysis of University E-Learning System

SIMULATION: TCP vs UDP Comparison
Topology: Two Students -> Router -> Server
TCP Application: FTP
UDP Application: CBR
TCP Protocol: TCP NewReno
Bandwidth: 1 Mbps (shared bottleneck)
Packet Size: 512 bytes
UDP Traffic Interval: 0.02 seconds
Traffic Duration: 9 seconds

TCP RESULTS
Packets Sent: 1626
Packets Received: 1626
Packets Dropped: 0
Packet Delivery Ratio: 100%
Packet Loss Ratio: 0%
Throughput: 797.37 Kbps
Average End-to-End Delay: 94.235 ms

UDP RESULTS
Packets Sent: 451
Packets Received: 451
Packets Dropped: 0
Packet Delivery Ratio: 100%
Packet Loss Ratio: 0%
Throughput: 205.26 Kbps
Average End-to-End Delay: 93.520 ms

OBSERVATION
Both protocols delivered all counted packets successfully.
TCP achieved higher throughput because FTP continuously generated
data, while UDP generated traffic at a fixed configured rate.
Both protocols experienced similar average end-to-end delays.
